🔍 Buscador de Usuários

Projeto desenvolvido para praticar consumo de APIs, manipulação de Arrays e Layout Responsivo.

##  Tecnologias
- HTML5 & CSS3 (Grid Layout & Flexbox)
- JavaScript (ES6+, Async/Await, Fetch API)
- Git & GitHub Pages

##  O que aprendi
- Como consumir dados reais de uma API externa (JSON Placeholder).
- Lógica de filtro avançada (busca por múltiplos termos separados por vírgula).
- Tratamento de erros (Try/Catch) para quando a API falha.
- CSS Grid para criar layouts que se adaptam ao celular automaticamente.
